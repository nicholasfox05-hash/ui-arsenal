# Contributing

Use Node 22+. Run `npm test` and `npm run check`. Keep changes focused and explain
how behavior was verified. Add regression coverage for search or import changes.

Never include private intake data. Use invented fixtures. Component contributions
need provenance, a compatible license, keyboard behavior, reduced-motion behavior,
responsive evidence and an honest list of deviations from their reference.

Do not mark a visual check passed from a unit test. Reference images and source
videos are not automatically redistributable. Prefer original code and link to the
creator rather than bundling their work without permission.
